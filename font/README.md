# Kalkulator do Tysiąca

### Czy grałeś/aś kiedyś w Tysiąca tak długo lub tak późno, że aż się ciężko liczyło punkty?
Teraz to już nie problem!
Przedstawiam Ci _**kalkulator do Tysiąca**_.
Po prostu wklep karty, które zdobyłeś/aś, a on Ci obliczy, ile masz punktów!

### Funkcje
Kalkulator automatycznie zaokrągla wynik do najbliższej 10, ale pamięta, ile miałeś/aś punktów,
więc nawet jeśli przypadkiem naciśniesz =, nadal możesz obliczyć swój dokładny wynik!
Dostępne są również tryby ciemny i jasny
